# Instruções do projeto

- Use a [especificação](docs/especificacao.md) como referência para o escopo e as regras de negócio.
- Use Conventional Commits e mantenha cada commit focado em uma mudança que possa ser revisada de forma independente.
- Após validar uma etapa de desenvolvimento, faça commit e publique as mudanças do projeto no GitHub. Preserve o histórico remoto e confira se o commit foi publicado.
